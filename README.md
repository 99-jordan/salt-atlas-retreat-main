# Salt Atlas Retreat

Salt Atlas Resort Studio — local app for resort page discovery, research, editing, and publish workflows.

## Development

You need Node.js (or Bun) — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
bun install
bun run dev
```

Or with npm:

```sh
npm install
npm run dev
```
